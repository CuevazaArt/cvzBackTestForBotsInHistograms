# Legacy Reference

Estos archivos provienen del proyecto **dorothy 7.0** (PecunatorCore) original. Se preservan **solo como referencia académica** del patrón mínimo de conexión a Binance REST y manejo de credenciales en texto plano.

> **No son parte del backtester nuevo.** La lógica equivalente vive en:
> - Conexión Binance: `backtester/core/downloader.py`
> - Credenciales encriptadas: `backtester/core/credentials.py`

Si necesitas mirar cómo se hacía antes, abre estos archivos. Si vas a copiar algo, hazlo a través de los módulos del backtester (`from backtester.core import ...`), no desde aquí.
